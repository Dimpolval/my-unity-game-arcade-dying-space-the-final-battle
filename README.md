# Умирающий космос: Последняя битва

# Краткое описание
Мини‑игра‑шутер: игрок управляет космическим кораблём, отражая волны врагов в напряжённых боях с полным обзором поля сражения. Как можно дольше сохранить последний выживший боевой корабль в гибнущей звёздной системе: каждый бой приближает либо спасение, либо окончательную гибель.

# Технологии
- Unity 2022.3.62f3
- C#
- UI Canvas
- TextMeshPro

# Платформа
- Windows
